# How to use:

1. You will need **Git** for this. To check/install Git on a MacBook, you can use Xcode Command Line Tools, which includes Git by default. Simply <u>open the Terminal and type</u> `git --version`; if it's not installed, it will prompt you to install the tools.
2. Clone the repository onto your machine. To do this open the folder you want the website files to go to, right click and click Open Terminal Here.
   Then type: `git clone https://github.com/timtim40a/o-kompletova-portfolio.git`
3. Install GitHub Desktop or Git extension for Obsidian (you'd be better off with the latter)#

> This is to make the process of creating new pages easier. Rather than sending me the .md file every time you have a new thing to post, you can do it yourself, as I have already added you to the repository as a co-author.
> Just edit the file, Git will show you the changes, commit it and go to your website to check. The changes should apply shortly (around 3 minutes max)

4. Open Obsidian and open the `public/pages` (found in the project structure of this repo) as a vault.
5. Navigate to `public/pages` in the project structure. To add a category to the navigation bar of your website just add a new folder. To add a new page, just go to the relevant category and create a new .md file there (if you are already in obsidian, just create a note there.)
6. You are ready to go!
